# ECO-BRIDGE

Учебная демоверсия маркетплейса вторсырья: React + TypeScript, Express, JSON.

## Запустить у себя
Установите Node.js 24 и pnpm 11.25.0. В папке проекта:

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

Откройте http://localhost:3000. Для разработки: `pnpm run dev`.
Проверка типов: `pnpm run lint`. Изолированные проверки обработчиков: `pnpm test`.

`build` собирает интерфейс в `dist/` и сервер в `server.js`.
`start` запускает готовый сервер без tsx и компиляции TypeScript при старте.

## Опубликовать на Render
1. В Render выберите **New → Web Service**, подключите https://github.com/bahasuperyt190-beep/ecoeco.
2. Выберите ветку **codex/fix-project-structure**.
3. Root Directory оставьте пустым, Runtime выберите **Node**.
4. Build Command: `pnpm install --frozen-lockfile --prod=false && pnpm run build`.
5. Start Command: `pnpm start`. Health Check Path: `/api/health`.
6. Выберите Free и создайте сервис. После успешного запуска Render выдаст адрес `https://….onrender.com`.
Можно использовать **New → Blueprint**: настройки записаны в `render.yaml`; убедитесь, что выбрана та же ветка.

Справка: https://render.com/docs/deploy-node-express-app
Ограничения Free: https://render.com/docs/free

Free-сервис засыпает после 15 минут без запросов, а первый запуск может занять около минуты.
Данные в JSON на Free сбрасываются при перезапуске, повторной публикации и засыпании.
Для демонстрации включены синтетические лоты и два демоаккаунта.
Постоянное хранение потребует отдельной базы или постоянного диска с изменением конфигурации.

GitHub хранит код. GitHub Pages обслуживает статические файлы и не запускает этот Express API.
Публиковать только `dist/` для этой версии недостаточно.

## Что изменено
- Сервер проверяет положительную конечную цену и количество от 50 кг/л или 0.05 т.
- Проверяются категория, единицы и диапазон координат; нулевые координаты сохраняются.
- Главная страница и QR-диалог обозначены как демоверсия без реального платежа.
- В итогах учитываются завершённые записи; литры не считаются килограммами без плотности.
- Добавлены синтетические лоты и демоаккаунты без реальных телефонов.
- Добавлены готовая серверная сборка, health endpoint и настройки Render.

## Границы демоверсии
Переключение демоаккаунтов — не аутентификация. Реального банка и IoT-устройства нет.
Сервер пока не защищает все операции и точные координаты: используйте только синтетические сведения.
Пользовательское тестирование не проводилось. Проверки обработчиков не заменяют тест с людьми.
Для реальной торговли нужны сессии, авторизация объектов, отдельное закрытое хранение адресов и проверенные банковские webhook-события.

## Если обновляете проект в AI Studio
Заменяйте файлы проекта с сохранением путей (`server.ts`, `src/…`, `package.json` и конфиги), а не вставляйте весь код в один HTML-файл.
Заново установите зависимости, соберите и опубликуйте проект средствами AI Studio.
Готовый архив соответствует этой папке; для предсказуемого размещения используйте шаги Render выше.

Исходная ссылка AI Studio этой публикацией не изменяется. После размещения используйте новый адрес сервиса в QR и отчёте.
